# رواد الرقمية — منصة التسويق وتوليد العملاء المحتملين
## مؤسسة رواد الرقمية للدعاية والإعلان — المملكة العربية السعودية

منصة تسويقية متكاملة وعالية التحويل (High-Conversion Marketing Website & Lead Generation System) مصممة خصيصاً لتحويل زوار الحملات الإعلانية المدفوعة (TikTok, Snapchat, Instagram, Facebook, Google Ads) إلى طلبات حقيقية وعملاء مؤهلين ومبيعات مسجلة.

---

### الهوية البصرية الرسمية
- **الشعار الرسمي:** تم اعتماد الشعار الأصلي لمؤسسة رواد الرقمية (Ruaad AlraQamia Marketing Agency) بالأبعاد والألوان الأصلية.
- **لوحة الألوان الأساسية:**
  - البنفسجي الملكي الداكن: `#320853` و `#56138A` و `#771BBD`
  - الذهبي المعدني: `#C99726` و `#F5D47A` و `#966F13`
  - الخلفيات الفاتحة: `#FAF9FC` و `#FFFFFF`
  - النصوص والحدود الرمادية الأنيقة: `#15101E` و `#4B5563` و `#ECE8F2`
- **الخط المعتمد:** خط تجوال `Tajawal` العربي الأصيل من Google Fonts.
- **التصميم:** تصميم سعودي متميز (Premium Saudi Digital Agency)، متوافق 100% مع الجوال والشاشات المختلفة (Mobile-First)، وبدون استخدام الوضع الداكن في الواجهة الرئيسية بحسب الاشتراطات.

---

### المعمارية والتقنيات
- **الإطار:** Next.js App Router (v16.4 / React 19)
- **اللغة:** TypeScript
- **التنسيق:** Tailwind CSS v4
- **الأيقونات:** Lucide React
- **الحركات:** Framer Motion / Motion
- **إدارة النماذج والتحقق:** React Hook Form + Zod
- **قاعدة البيانات:** MongoDB Atlas مع Mongoose (المرحلة الثالثة)
- **الأمان:** Server-side validation, Secure cookies, CSRF protection, Rate Limiting
- **التتبع المتقدم:** Meta Pixel + CAPI, TikTok Pixel + Events API, Snapchat Pixel + CAPI, Google Analytics 4, Google Ads Tracking (المرحلة الرابعة)

### التشغيل المحلي (Windows)
```bash
# 1. الدخول إلى مجلد المشروع
cd C:\Users\mradd\.gemini\antigravity\scratch\rowad-digital

# 2. تثبيت الحزم (إن لم تكن مثبتة)
npm install

# 3. إعداد ملف البيئة
copy .env.example .env.local

# 4. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`
